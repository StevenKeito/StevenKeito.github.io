Visual Audit

Color palette

New York Times

  • A classic foundation of black ( rgba (0, 0, 0, 1) )
  • White ( rgba (255, 255, 255, 1) )
  • Accented with a bold saffron ( rgba (246, 203, 47, 1) )

The Guardian visual audit

  • Text color ( rgba (18, 18, 18, 1) )
  • Background color ( rgba (255, 255, 255, 1) )
  • Background primary color ( rgba (5, 41, 98, 1) )
  • Tab color ( rgba (255, 229, 0, 1) )
  • Head Title size ( Width = 324px, Height = 108px )
  • Typeface ( GuardianTextSans font family, GH Guardian Headline, Guardian Egyptian Web, Georgia, serif )
  • Media Types used (daily print newspaper, website, mobile app, podcasts, and live blogs)
  • The primary functions of the Guardian are to deliver independent journalism, to present a global perspective, and to amplify unheard voices worldwide.

The Washington Post visual audit

  • Text color (rgba(17, 17, 17, 1)
  • Background color (rgba(247, 247, 247, 1)
  • Title size (520 x 80px)
  • Typefaces (Postoni, Franklin, Arial, Helvetica, Sans-serif)
  • Media type (Images. Advertisements, games, Ai chat)
  • Their primary function is to inform as many people as they can of the truth of what is happening in the world right now.

The Wall Street Journal Visual Audit

  • Text Color ( rgba (0, 0, 238, 1) )
  • Background color ( rgba (247, 247, 247, 1) )
  • Title size (570px x 65px)
  • Typefaces ( Retina, Helvetica, Arial, sans-serif )
  • Media Types ( daily print newspaper, WSJ magazine, audio, mobile app, and interactive content)
  • The primary functions of the Wall Street Journal are to report on politics, world affairs, technology, science, and to provide coverage of the stock markets, banking, corporate news, and the global economy.
